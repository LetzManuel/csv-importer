# CSV Importer (installable app)

The built, installable web app for checking, fixing and building Coupa CSV import files. It works offline.
Open https://letzmanuel.github.io/csv-importer/ and install it from the browser.

This repository contains only the built app files. It holds no customer data, secrets or settings: all data stays in the user's browser and, if they sign in, in their own OneDrive.

**Offline single file:** [offline/coupa-forms-offline.html](offline/coupa-forms-offline.html). Download it and open it from disk. It works without any server; cloud sync is available only in the installed app.
